## Finding And Correction

The historical Claude+Codex+AGY fixture reproduced an upstream collision:
Codex and AGY both owned ten `.agents/skills/speckit-*` files with different
command syntax. Spec Kit 1.0.3 reported `unsafe-multi-install`, managed-file
collisions, and `Integration status: ERROR`.

The reviewed reconciliation plan contained only:

```text
specify integration uninstall agy
specify integration uninstall codex
specify integration upgrade claude
```

No command used `--force`. The resulting status was `OK`, with manifest
`1.0.3:claude`, zero modified/missing/invalid managed files, and Claude as the
default integration. Codex and AGY remain Mesh worker providers through the
provider-neutral delegation envelope; they do not own project-local Spec Kit
skills concurrently.
